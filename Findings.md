**ESLint** is a static code analysis tool for identifying problematic patterns in JS.
helps devs to find and fix code quality and style.

**Prisma** an ORM(Object Relational Mapping)tool , to define your database schema and models.
COntains details about data sources , generators and the data model itself, allowing devs to interact with databases in a type-safe manner.

**Docker** is a platform that enables developers to package applications into containers, which are isolated environments that contain the application code and all its dependencies.
makes it easier to build, ship, and run applications.

**Docker Compose** is a tool for defining and running multi-container Docker applications.
It uses a YAML file to configure the application's services, networks, and volumes, making it easier to manage complex applications.
